## 本会话贡献

### 契约

- `SessionSummary` 增加 `kind`（conversation / run）、`folderId`、`entryCount`；`SessionRecord` 升级为 schemaVersion 2。
- 新增 `SessionFolder`、`SessionTreeNode`、`SessionTree`、folder CRUD / session move DTO；IPC 增加 `session:tree` / `move` / `createFolder` / `renameFolder` / `moveFolder` / `deleteFolder`。
- preload / `bridge.d.ts` 暴露对应白名单方法。

### Session 存储

- `SessionStore` 改为真实目录树：`sessions/<folderId>/.../<sessionId>/session.json` + 每层 `folder.json`；folder / session id 做目录名，标题只放元数据。
- 支持递归文件夹创建 / 重命名 / 移动 / 删除、session 移动；移动文件夹禁止进入自身或后代；路径只接受 `fld_` / `ses_` id。
- 草稿目录首次读取时自动创建「草稿」，并写入 `manifest.settings.draftSessionFolderId`；草稿目录及祖先禁止删除。
- v1 `SessionRecord` 读取时迁移为 v2（conversation / null folder / entryCount 0），保存写 v2。
- session / folder 的目录名与 JSON id 不一致、损坏的 folder/session 在树扫描时跳过；单条读取报 `E_IO`。
- run session 先支持 opaque `history` + `entryCount`，`RunResult` 校验留给 M7.4。

### 工作区设置与服务接线

- `WorkspaceStore` 增加 `getSettings` / `updateSettings` 与 `draftSessionFolderId` 字段。
- `SessionService` 把工作区设置回调传给 `SessionStore`；主进程装配 IPC 与 handler。
- Blob refs / GC 清理以 TODO 记录，待 M7.4 接线。

## 本会话贡献

### 修复：常量内联输入重复 / 无法正常输入

- `InlineNodeConfig` 的 Constant 输入改为本地 draft：输入过程中不再每次按键都写回 GraphDocument；
- 兼容中文 IME composition：composition 期间不提交，compositionEnd 后 450ms 兜底提交；
- 失焦 / Enter 立即提交，Escape 放弃草稿；外部 config 变化只在未聚焦时同步；
- 避免输入时重建节点对象导致的光标跳动与重复字符。

### 修复：框选闪烁与卡死

- `CanvasView` 拆开「文档投影」与「选中同步」两个 effect：框选只更新节点 selected 标志，不再重建全部节点对象；
- `onSelectionChange` 用 `sameNodeSelection` 去重，父组件 state 未变化时不再触发重渲染；
- 选中同步先更新 ref，阻断 React Flow / 父 state 之间的循环回调；
- 新增 `canvas/core/selection.ts` 纯函数与单测。

### 验证

- 逐键输入测试：聚焦常量输入后模拟输入 `hello`，最终 DOM 与落盘 config 均为原值 + `hello`，没有重复字符；
- 框选压力测试：连续 8 轮框选 + 清空，每轮选中数稳定为 2，无闪烁、无卡死；
- FH：28 个测试文件 / 138 项测试通过；
- `pnpm typecheck`、`pnpm build`、`pnpm smoke` 通过。

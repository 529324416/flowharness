## 本会话贡献

### 工作区节点预设库

- 新增 `documents/presets/library.json`，使用 `DocumentRef.kind = "presetLibrary"` 复用 WorkspaceStore 的 revision / 原子写 / 4 MB 上限，不新增 main 服务与 IPC；`.fhws` 导出自动包含节点库。
- 数据模型：`schemaVersion / folders / presets`；文件夹 id + title + parentId；预设记录保存 `type / typeVersion / config / folderId / tags / 时间戳`，id 即 wireclaw `NodePresetDocument.presetId`。
- 渲染层 `renderer/src/presets/`：`PresetLibraryProvider`（加载 / 串行保存 / CRUD）、纯模型 `model.ts`（树、移动、删除上移、序列化 / 搜索）、`presets/bus.ts`（全局入口 → 工作台 View 的请求总线）。

### 两套 UI

- **插入菜单**（`NodeLibraryPalette`）：最近使用 → 用户库文件夹 → 内置预设 → 节点类型；搜索、↑↓ + Enter、点击插入、条目拖拽到画布（CanvasView 负责屏幕 → 画布坐标换算）。
- **管理模式**（`PresetManagerDialog`）：左文件夹 / 预设树（搜索、新建文件夹、展开收起），右侧编辑名称、简介、文件夹与 configSchema 默认参数；删除文件夹时内容上移到父级；保存即时落盘。
- 画布节点右键新增「创建预设节点」：命名 Modal（名称 / 简介 / 文件夹）+ 捕获节点 type / typeVersion / config；创建后打开管理 Modal 并定位到新预设。
- 全局入口：标题栏「视图 → 节点库 / 管理节点库…」、`Ctrl+Shift+N` / `Ctrl+Shift+M`；插入菜单与管理 Modal 互斥。

## 本会话贡献

### wireclaw：RunResult v1

- 新增 `RunResult` / `RunResultEntry`（`model-call` / `session` 判别联合）类型，`GraphRunResult` 增加 `graphId` / `entries`。
- 新增 `RunResultCollector`、`createRunResult`、`RunResultSerializer`（JSON 校验、SessionData 规范化、附件指纹汇总）。
- `NodeContext.collect` 供节点提交条目；ModelCall（chat / generate，成功与失败）与 AgentRun 采集结果，运行时补齐 `id / nodeId / nodeType / graphPath`。
- Subgraph / Loop / ForEach 共享 root collector，`graphPath` 以数组向上冒泡。
- 新增 `harness-run-result` 测试（采集、失败条目、嵌套路径、附件、非法结构）。

### FH：持久化与契约

- contracts：`run:result`、`session:saveRun`、`session:setDraftFolder` 及 DTO；preload / `bridge.d.ts` 同步。
- `RunStore` 增加 `result.json` 读写；`RuntimeHost` 在运行结束时生成 RunResult、持久化并缓存，`getResult` 支持进程内与跨重启读取。
- FH 持久化前把 `RunResult.runId` 改写为自身稳定 runId，与 `runs/<runId>`、run session、UI 引用保持一致。

### Session 与回放

- `SessionStore` 按 `kind` 校验 history：run 会话必须通过 `RunResultSerializer`，`entryCount` 与附件指纹自动派生；新增 `createRunSession`（默认草稿目录）与 `setDraftFolder`。
- `session:saveRun` 从 RunStore 装载结果并写入 run 会话；「保存到会话」后自动切到运行模式并打开会话历史面板。
- `SessionHistoryView` 按 `kind` 回放：conversation 走 `SessionData`，run 走 `RunResultView`。
- Session 树文件夹右键新增「设为草稿目录」，持久化到 workspace settings；外部新增会话后通过 revision 自动刷新。

### 运行结果面板

- 运行日志新增「结果」页签：输出、模型调用 / Agent 会话条目、附件、耗时与 usage；空态区分「没有条目」与「暂无结果」。
- 日志页签补全 `node:end` 输出键与 `node:stream` 文本预览；条目渲染复用会话消息卡片；附件均通过 `fh-asset://` 与 `blob:stat` 展示。

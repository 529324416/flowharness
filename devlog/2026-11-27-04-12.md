# 开发日志 — 2026-11-27（Provider 体系重构 M9.0–M9.6）

## 背景

M9 把「AppConfig.providers + 手填 providerId/modelId」重构为「API Key 库 + Provider Profile + 持久化模型目录」，让密钥只在 main、图只引用 profile id，并补齐设置页、节点下拉、健康提示与 Provider 节点。

## M9.0 / M9.1 决策、契约与数据层

- 决策 API Key 与 Provider Profile 分离（ADR-029）：key 是凭证，profile 是 adapter + key + endpoint + 模型目录；图只保存 `providerId` / `modelId`。
- 新增 `@flowharness/contracts` Provider 库契约：协议、adapter、`ApiKeyRecord`、`ProviderProfile`、`ModelCatalogEntry`、健康状态与 IPC DTO。
- 新增应用级 `%APPDATA%/FlowHarness/provider-library.json`：宽容读、严格写、原子写、损坏备份、`E_MIGRATION`。
- 影子迁移：旧 `AppConfig.providers` 与 `secrets.bin` 迁移为 profile / key，保留旧 id；引入两阶段 AppConfig v1 → v2，避免库写失败丢配置。

## M9.2 运行时、健康与 IPC

- wireclaw `SessionError.httpStatus`；`node:error` 通过失败节点的 `model` 输入边回溯 `providerId`，并沿 `origin` 链读取状态码。
- `ProviderRegistry` 改为库驱动：profile + key + adapter 工厂；启动只读库不联网，刷新模型才访问 Provider。
- 401/403 → key `invalid`；402/429 → `quota`；网络 / 未验证 → warning；结果持久化并广播 `provider` topic。
- 真实 DeepSeek key 探测通过（2 个模型）；无效 key 返回结构化 401。

## M9.3 设置页、AppConfig v2 与会话回退

- 新增 `providers/ProviderLibraryDialog`：API 密钥 / Provider 两区；密钥添加验证、重新验证、替换、删除；Provider 编辑 / 启停 / 刷新模型 / 删除引用检查。
- `ProviderLibraryProvider` 加载只读视图并监听 `provider` topic；设置页与设计器共用。
- AppConfig v2：移除 `providers`；只有库文件确认存在后才 finalize；默认 4 条 Provider 播种；旧 secrets 镜像清理；旧 IPC / 旧设置页移除。
- 修复 Modal 内下拉层级：新增 `--fh-z-popover`（250 > modal 200）。
- 受限环境（AppData 不可写）：secrets / library 修改回退到 main 内存，`ProviderLibraryView.persistenceError` 统一提示；密钥可验证为 `active` 并在本次会话运行，不再出现 `Internal error`。

## M9.4 节点下拉与健康提示

- `core.model` 的 `providerId` / `modelId` 变为 Provider / 模型下拉；无目录回退文本输入；节点摘要 `provider · model`。
- 节点标题右侧健康三角：profile 缺失 / 禁用、缺 key、model 不在目录、key invalid / quota / unverified。
- provider 问题合并进运行日志：缺 profile / model 为 error 并阻断运行；key 失效 / 未验证为 warning，允许尝试。

## M9.5 Provider 节点与连线（方案 C）

- wireclaw 新增 `provider` 端口值类型 / `ProviderRef`，`HarnessValue`、`isHarnessValue`、端口兼容与编辑器目录同步扩展。
- 新增 `core.provider`：无输入、单 `provider` 输出，config 只含 providerId，不持有实例 / 密钥 / 模型。
- `core.model` 增加可选 `provider` 输入：连接优先，未连接回退 config.providerId；configSchema 只要求 modelId，旧 graph 不受影响。
- FH：Provider 节点进入节点库 / 检查器；连接后的 Model 摘要显示来源 Profile；Provider 节点承担 profile 健康，Model 不重复报错。
- 修复右键「添加节点」落点：屏幕坐标换算为画布坐标，避免平移 / 缩放后插到视口外。
- wireclaw 新增 provider 值 / 节点执行 / 图校验测试，68/68；FH 42 文件 / 229 项。

## 2. 节点折叠模式（ADR-042）

- Header 右侧新增折叠按钮（`ChevronsUp` 折叠 / `ChevronsDown` 展开，`aria-pressed`），点击写入 `node.ui.collapsed`；新增 `setNodeCollapsed` CanvasCommand，折叠切换进入撤销栈并随文档自动保存；
- 新增 `designer/core/collapse.ts`：按「有数据且不等于节点默认值」计算折叠态保留字段——默认值取 `configSchema.properties.*.default` 与类型 `defaultConfig`，空字符串 / 空白 / 空数组 / 空对象不算数据，布尔值仅 true（或默认 true 被改为 false）保留；
- 折叠后隐藏 kind 标签，只显示已连接端口（数据行与徽标）与保留字段；未连接端口的徽标、空参数行、空 Constant 一并隐藏，展开后恢复；运行期只读时隐藏折叠入口；
- `InlineNodeConfig` 通过 `FieldRow` 按字段名过滤，Canvas 组件不读取节点语义；adapter 在折叠时注入 `collapsedFields`；
- 新增 `designer-collapsed` 截图场景与视觉基线 `ui-node-collapsed.png`。

## 3. 工作流多选与批量操作（ADR-043）

- 工作流列表支持多选：`Ctrl` / `Cmd` 切换额外项、`Shift` 从「最近点击 / 打开」的锚点连选、普通点击打开并清空；**高亮即选中**——打开中的工作流始终属于选择，与额外项共用同一高亮，不引入勾选 / 强调边框等第二视觉；
- 批量操作条：已选数量 / 全选 / 复制 / 删除 / 清除；选中项右键菜单切换为批量菜单（打开当前项 / 复制所选 / 删除所选 / 清除）；
- App 层新增 `handleDuplicateDocuments` / `handleDeleteDocuments`，单选入口复用同一实现；批量删除确认 Dialog 列出数量与标题，逐条调用既有 `workspace:deleteDocument`，只 flush / 等待工作台保存链 / 刷新一次；批量复制不切换当前文档（单选保留切换副本行为）；
- 新增纯函数 `shell/workflow-selection.ts`（toggle / 区间 / 清理 / 排序）与 `workflow-selection.test.ts`；补充 `shell/**` 到 vitest include（此前 shell 下的会话历史测试未被执行）；
- 新增 `designer-workflow-select` / `designer-workflow-batch` / `designer-workflow-shift` 截图场景；基线 `ui-workflow-multi-select.png`；批量复制 / 删除用 `designer-workflow-batch` 验证 27 → 29 → 27（复制两份副本后删除这两份，净变化为零）；Shift 连选用 `designer-workflow-shift` 验证普通点击后连选 1 → 4 → 6，Ctrl 取消一项回到 5。

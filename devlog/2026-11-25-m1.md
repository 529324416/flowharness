# 开发日志 — 2026-11-25（M0 / M1）

## 本会话贡献

### M0 — 文档持久化

- 新增 `workspace:readDocument` / `workspace:saveDocument` 契约与 preload 桥；
- `WorkspaceStore` 支持文档快照读写、SHA-256 revision、4 MB 上限、JSON 校验与原子写；
- `E_CONFLICT` 显式暴露陈旧 revision；保存按 workspace + ref 串行化；
- ADR-012 固化“快照 + 内容哈希 revision”的保存策略。

### M1.1 — 数据与视图契约

- `canvas/core` 改为纯 `CanvasNode / CanvasEdge / CanvasDocument / CanvasPort / CanvasCommand`；
- 新增单向 `GraphDocument → CanvasDocument` adapter；
- 画布命令回写 `GraphDocument`：move / remove / connect / disconnect / setViewport；
- `CanvasView` 改为受控视图，示例数据改为 GraphDocument fixture。

### M1.2 — 只读设计器

- 设计器按工作区加载 `main` GraphDocument，不存在时创建 `Constant → Output` 模板；
- 启动自动打开最近工作区，无工作区时显示空状态；
- 画布按真实端口渲染 Handle，节点高度随端口数变化；
- revision 进入文档 state，为自动保存做准备。

### M1.3 — 运行可视化

- renderer 侧 `Graph.validate`，有 issue 阻断运行；
- TitleBar 增加运行 / 取消控制；
- 运行事件投影到节点状态、运行日志与 StatusBar；
- 运行只消费当前 runId 的事件，并缓冲响应前到达的事件。

### M1.4 — 编辑与自动保存

- 启用节点拖动、连线、断线、删除、添加节点与 viewport 持久化；
- 新增节点库菜单、唯一节点 id 与 2 列网格摆放；
- 新增 400ms `SaveCoordinator`：串行保存、revision 更新、冲突停止、卸载 flush；
- StatusBar 展示已保存 / 保存中 / 保存冲突 / 保存失败；
- 切换工作区 / 卸载时尽量 flush。

### M1.5 — 检查器与收口

- 属性检查接入选中节点：类型、版本、端口、依赖、运行状态；
- 未选中时显示图级信息；
- 原始 JSON config 编辑、格式化、解析错误与自动保存；
- 补充 README / 架构文档 / 设计文档 / TODO 状态；
- ADR-013 ~ ADR-016 固化 GraphDocument 事实源、canvas core 边界、wireclaw 浏览器构建边界与自动保存协调器。

### 工程与文档

- `capture:ui` 增加 designer / designer-run / designer-edit / designer-drag / designer-config 场景；
- 重拍画布、缩放、设计器、编辑与运行基线。

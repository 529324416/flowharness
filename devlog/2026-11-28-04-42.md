# 开发日志 — 2026-11-28（Provider / API 密钥设置页重构）

## 1. 设置页改为列表 + 属性栏

- **API 密钥**页签：移除列表上方的内联新增表单，整块区域改为「左侧密钥列表 + 右侧属性栏」；列表项显示名称、协议、指纹与状态，右侧显示指纹、Base URL、验证 / 创建 / 更新时间与最近错误；
- 密钥属性栏保留重新验证 / 替换 / 删除；替换在当前属性栏内展开输入行；
- **Provider**页签采用同一结构：左侧 Provider 列表显示名称、适配器与健康状态，右侧属性栏直接编辑名称 / 适配器 / API 密钥 / Base URL / 默认模型 / 启用，并展示模型目录与刷新时间；
- Provider 的「保存」只在草稿与当前 profile 不一致时可用；刷新模型 / 删除保留在属性栏；
- 选中项跟随库刷新：仍存在则保留，删除后回退到第一条；新增成功后自动选中新条目。

## 2. 新增表单移入 Modal

- API 密钥「新增」打开独立 Modal，内容即原内联区域：协议 / 名称 / API Key / Base URL 四个字段；提交仍按协议调用 main 验证并展示就地错误；
- Provider「新增」使用同一套字段（名称 / 适配器 / API 密钥 / Base URL / 默认模型 / 启用），创建成功后关闭 Modal 并选中新 profile；
- 两个 Modal 均复用 `ui/Dialog`，嵌套在设置页之上；表单错误在 Modal 内展示，全局成功 / 失败提示仍留在设置页顶部。

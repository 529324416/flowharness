# 开发日志 — 2026-11-27 / 28（表单控件、数据端口与端口徽标）

> 本会话只保留这一篇。只记录实际交付，不记录过程、排错和实现细节。
> 上一阶段见 [2026-11-27-08-35.md](./2026-11-27-08-35.md)。
> 本会话从 UI 样式打磨推进到 wireclaw 节点数据端口化与端口渲染重构，决策见 ADR-037 ~ ADR-041。

## 1. 表单控件收口（ADR-037）

- 节点内联的原生 `<select>` 全部改用 FH `ui/Select`：Constant 的 text/json、Model Call 的 mode / modality、Agent 的 permission、Log 的 level；新增 `inlineSelect` 保留 22px 紧凑高度与默认边框。
- 全局移除 `input` / `select` / `textarea` 的聚焦描边与 focus 期边框变化，焦点只由光标表达；按钮 / 链接仍保留 `--fh-border-focus` 焦点环。
- `ui/Checkbox` 增加 `compact` 变体（12px 方框、10px 文案、不占 32px 控件高度）；Value 的必填、Model Call / Agent 的思考、Loop 的失败重试、批量运行的图选择全部改为自绘勾选。
- 上游连接固定字段升级为 `CanvasLockedField { value, reason }`：画布渲染只读行（锁图标 + 上游值 + 「上游」），检查器同字段禁用并显示锁定原因。

## 2. JSON 代码主题（ADR-038）

- 新增 `ui/json-highlight`：把 JSON 源码扫描为 key / string / number / boolean / null / punctuation / plain token，空白与非法字符逐字保留。
- 新增 `ui/CodeArea`（透明 textarea + 同字体高亮层、滚动同步）与 `ui/JsonCodeText`（只读着色文本）；接入节点内联 JSON、检查器 schema 表单的 JSON 字段、检查器「JSON」页签与 Constant 阅读态预览。
- 新增 token `--fh-code-*`：深色取 VS Code Dark+ 去饱和色，亮色给出对应浅色值。

## 3. 未选择模型（ADR-039）

- Model ID 下拉空值项去重：工作台注入「未选择模型」，节点内联只在缺失时补一条（`withEmptyOption`）。
- `missing-model` 保留 error 级别用于节点提示，但移出阻断集合与问题列表：不弹 Provider 横幅、不禁用运行，只在节点标题保留红色叹号与 tooltip；若直接运行则在节点执行期报错。

## 4. 节点数据端口化与本地回退（ADR-040）

- wireclaw `core.model.call` 新增 `system` / `parameters` 输入，config 新增 `providerId` / `modelId` / `prompt` / `attachments`；`core.agent.run` 新增 `system` / `hostTools` 输入，config 新增 `providerId` / `modelId` / `input` / `attachments` / `toolset`。
- 执行期先做端口覆盖、未连接时回退本地 config；`model` / `prompt` / `input` 的 `required` 移除，缺值改为节点执行期报错。
- 画布把任何受支持端口连接投影为字段锁；检查器同步禁用。Model Call / Agent 增加本地 Provider + Model 下拉，连接 `model` 端口后锁定并保留回退值；切换 Provider 时清空目录中不存在的模型。
- Agent Run 图标改为 `Bot`，Model Call 改为 `BotMessageSquare`。
- 新增 FH 测试：Model Call 仅靠本地 `providerId` / `modelId` / `prompt` 配置即可完成运行。

## 5. 端口徽标与数据行（ADR-041）

- 节点 Body 顶部新增数据行：先列输出端口（优先），再列没有对应字段的输入端口；底部端口列表移除。
- 端口徽标与节点主体保持 **5px** 间距，上边缘严格对齐数据行上边缘；位置按 `offsetTop` 布局链测量（未缩放整数坐标），并在测量后调用 `updateNodeInternals`，拖动 / 高倍缩放时不再跳变。
- 未连接 = 灰色 **20px** 圆角方块 + **10px** 数据类型图标（居中）；已连接 = 橙红色 **20px** 空圆环 + **6px** 实心点，不显示类型。
- Handle 与视觉徽标解耦：react-flow 对 Left / Right 句柄取外缘作为端点，因此改用 6px 透明句柄（未连接对准方块中心、已连接对准实心点底部），视觉徽标独立渲染、命中区覆盖整块徽标；`SciFiEdge` 不再绘制连线端点小圆，连线终点就是实心点底部。
- 端口颜色只由连接状态决定（`--fh-port-idle` / `--fh-port-connected`），节点边框与端口不再因选中或运行状态改变颜色。
- 字段顺序调整：**可接入端口的数据优先于只能本地编辑的参数**；同组内按必要数据 → 必要参数 → 常用标量 → 结构数据。
- 截图场景 `designer-controls` 扩展为端口/表单综合基线；新增 `designer-json` / `designer-json-read` / `designer-model-empty`。

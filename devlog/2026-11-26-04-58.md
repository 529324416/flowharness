## 本会话贡献

### M7.4.2 运行消息写入 conversation 会话

- 新增 `run-conversation`：把 `RunResult` entries 转成真实消息——Agent `session` 条目直接使用完整 `SessionData`，ModelCall 条目按实际输入 / 输出重建 system / user / assistant（含附件、thinking、usage、stopReason）。
- `SessionStore.appendRunMessages`：只允许写入 `kind: "conversation"`，追加后重新派生 `messageCount` 与附件指纹；run session 仍只存 `RunResult`。
- 新增 `session:appendRun` IPC；运行模式下选中 conversation 会话时，run 结束自动追加一次（同一 run 去重）；结果面板提供「写入对话」手动入口。
- 进入运行阶段时若没有 conversation 会话，自动创建「运行对话」；写入后刷新会话历史面板与 Session 树计数。
- ADR-022 记录消息写入与 run session 分离的决策。

### M7.5 运行模式骨架

- `WorkbenchDefinition` 增加 `RunView`；`WorkbenchHost` 按 `mode` 选择主视图。
- `harness-designer` 运行阶段显示「运行模式」上下文条与「返回设计」，画布 / 浮动面板 / Session 导航保持不变。
- `WorkbenchInstanceDocument` 持久化 `mode` / `runId` / `sessionId`；打开工作台时恢复阶段与选中会话，切换阶段与会话时写回实例。
- 导航与运行条统一走 `handleWorkbenchModeChange`：进入运行阶段优先保留已有 conversation 会话。
- 动画原语与自定义 RunView 运行页仍未实现。

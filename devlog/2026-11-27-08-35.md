## 本会话贡献

### Provider 节点内联下拉

- `core.provider` 的 Body 从只读摘要改为 Provider 下拉，选项来自 Provider 库；缺失的当前值以占位项保留。
- 下拉改用 `ui/Select`（Radix 菜单 + FH token），不再是原生 `<select>`；保留默认边框，仅去掉 focus 时的 outline / ring，避免看起来像 label。
- 下拉保留「未选择 Provider」项，可清空 Provider 节点自身的选择。

### Model Provider 连接约束

- Model 的 `provider` 输入连接来源 Provider 后，检查器 Provider 字段显示来源 Profile、禁用编辑；JSON 写入也会保留已有 `providerId`，连接优先级不变。
- Model 节点的 Provider 输入槽显示来源 Profile 名称，而不是端口名；Model 下拉改用来源 Provider 的模型目录。
- 连接 Provider、切换 Provider 节点或连接中改写 Model config 时，按 Provider 库的持久化模型目录校验 `modelId`；不存在时清空并显示可关闭的「模型已清空」警告。目录为空时不误清空。
- 连接 / 切换 Provider 会把来源值同步到 Model 的 `config.providerId`，作为断开连接后的回退。
- Model ID 下拉始终提供「未选择模型」项，可退选当前失效模型；Provider 目录为空时字段下方提示先在设置页刷新模型。
- 模型目录按需自动刷新：Model 引用的 profile 目录为空且没有 `modelsFetchedAt` 时，后台调用真实 `provider:models:refresh`；成功持久化并广播，失败保留空目录并在检查器提示；同一 profile 每个文档会话最多自动尝试一次。

### Constant 阅读 / 编辑模式

- 默认渲染为 `<p>`：正文按 200 字符裁剪、最多 3 行；hover 用 Tooltip 展示最多 400 字符。
- 标题栏新增铅笔 / 对勾按钮切换编辑模式；编辑态使用随内容自增高的 TextArea（上限 180px），退出后恢复 p 标签；编辑态可切换 text / json，json 使用紧凑 JSON TextArea。
- 两种模式都关闭拼写检查、自动纠正与自动大写，移除红色波浪线。
- Tooltip 材质改为与浮动面板一致的半透面板（`--fh-panel-bg` + `--fh-panel-alpha`）。

### 节点全量内联属性

- Model 节点 Body 增加 Provider 与 Model 两个 FH 下拉；连接 Provider 时 Provider 下拉锁定，Model 仍可直接切换。
- Model Call 补齐 system / think / thinkingLv / temperature / modality / parameters；Agent 补齐 system / think / thinkingLv / temperature / hostTools；ToolSet 补齐 include / exclude / hostTools。
- Loop / ForEach / Subgraph 补齐 graph JSON，Loop 增加失败重试，Event Trigger 增加事件名；对象与内嵌图使用紧凑 JSON TextArea，失焦解析、失败就地提示。
- 节点高度随 config 字段增长；只读时保持同一套控件结构并禁用。

### 浮动面板布局按 Graph 持久化

- `GraphDocument.ui.panels` 保存 `inspector` / `run-log` / `session-history` 的 open / collapsed / x / y / width / height / z。
- 打开 Graph 时应用保存布局；无布局的旧图回退默认。
- 面板拖动 / 缩放 / 折叠 / 开关停稳 400ms 后写回当前文档，不进入撤销栈；容器尺寸变化后的钳制坐标也会写回。

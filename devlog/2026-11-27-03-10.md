## 本会话贡献

### 运行即自动创建会话

- 点击运行时，在**工作区草稿目录**自动创建一条空 conversation 会话（标题「运行 · 工作流 · HH:mm」），自动选中并打开「会话历史」浮动面板。
- 运行开始前完成创建（`onRunWillStart` 改为可异步并 await），避免首条消息早于会话；工作台实例的 `sessionId` 仍由现有逻辑持久化。
- 进入运行模式不再自动创建「运行对话」；会话只在实际运行时创建。

### 运行中逐步写入

- wireclaw `GraphRun` 暴露只读 `resultEntries`（RunResultCollector 快照）。
- contracts / main / preload 新增 `run:entries`：运行中读取已采集 entries。
- 新增 `session:appendEntries`（合成 RunResult 校验 entries，复用 ADR-022 的消息转换）与 `session:appendMessage`（输出摘要 system 消息）。
- renderer 每 450ms 轮询 entries，按 `entry.id` 去重后增量追加；运行结束补最后一批，并把输出端口的文本 / JSON / 附件标记写成摘要；Session 树计数与历史面板随每次追加刷新。

### 移除结果页签与手动保存

- 运行日志只保留「日志 / 问题」；移除「结果」页签和「保存到会话 / 写入对话」按钮。
- `RunResult` 仍写 `runs/<runId>/result.json`；run session（`kind: "run"`）与 `session:saveRun` / `session:appendRun` 接口保留，不再有 UI 入口。

### 修复 token 流导致画布闪烁

- `applyRunEventsToView` 改为引用稳定：`node:stream` 等不改变节点 / 边状态的事件返回原 `RunViewState`，只有实际状态变化才产生新对象。
- `CanvasView` 改为 `memo`：App 的高频 `runEvents` 更新不再触发画布重渲染；token 流只更新运行日志 / 会话面板。
- 新增引用稳定单测（stream 事件后 view 对象不变）。

### 文档与测试

- 新增 ADR-028；ADR-020 / ADR-022 标注状态变化；同步 readme / architecture（README、overview、modules、runtime、ui、data-model、decisions、dev-environment）/ todo。
- session-store 增加 appendEntries / appendMessage 用例；37 文件 / 189 项。

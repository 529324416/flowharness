## 本会话贡献

### M8.1 工作台模板与节点预设

- 新增 `workbench/templates.ts`：6 条模板覆盖 Harness 设计器（空白 / 当前工作流）、节点清单、批量运行、运行页（空白 / 当前工作流）；模板可创建起始 `GraphDocument`，复用现有保存 → 刷新 → 打开流程。
- WorkbenchMenu 改为「从模板新建」，不再只按注册类型创建空实例。
- 内置节点预设增加「图片生成」（`core.model.call` generate / image），共 4 条；预设测试同步。
- 新增模板单元测试：唯一 id、类型合法、空白模板生成 Constant → Output。

### M8.2 `.fhws` 导入导出 UI

- contracts / preload / bridge 增加 `workspace:exportArchive` / `workspace:importArchive`；main 通过系统保存 / 打开对话框处理路径。
- 文件菜单新增「导入工作区 (.fhws)」「导出当前工作区 (.fhws)」；无工作区时导出禁用。
- 冲突策略：导入总是创建新 workspace id 的副本，不合并、不覆盖；档案仍不含 `runs/` / `sessions/`。
- 工作区测试增加“同一档案重复导入得到独立副本、原工作区不受影响”。

## 2. 节点折叠模式（ADR-042）

- Header 右侧新增折叠按钮（`ChevronsUp` 折叠 / `ChevronsDown` 展开，`aria-pressed`），点击写入 `node.ui.collapsed`；新增 `setNodeCollapsed` CanvasCommand，折叠切换进入撤销栈并随文档自动保存；
- 新增 `designer/core/collapse.ts`：按「有数据且不等于节点默认值」计算折叠态保留字段——默认值取 `configSchema.properties.*.default` 与类型 `defaultConfig`，空字符串 / 空白 / 空数组 / 空对象不算数据，布尔值仅 true（或默认 true 被改为 false）保留；
- 折叠后隐藏 kind 标签，只显示已连接端口（数据行与徽标）与保留字段；未连接端口的徽标、空参数行、空 Constant 一并隐藏，展开后恢复；运行期只读时隐藏折叠入口；

- 新增 `designer-collapsed` 截图场景与视觉基线 `ui-node-collapsed.png`。

## 4. 运行态动画语义（ADR-044）

- 边的动画改为「只有数据输出时才有」：`node:start` 不再点亮入边，`node:stream` 点亮出边，`node:end` 立即熄灭；普通值节点在结束瞬间完成交付，不再留下持续流动的旧动画；
- 边动画改为百分比进度扫过：白色 path（`pathLength=100`）的 `stroke-dashoffset` 从 -100 走到 0，500ms 循环（0% 全灰 / 50% 半白 / 100% 全白），灰色底由原连线提供；
- 运行节点：橙红描边 + 2px 斜纹警戒环（由四条 2px 边框拼成、中间完全透明，条纹 500ms 平移，未使用 mask-composite），保留原有脉冲；
- 完成冷却：`completed` 时挂 1.5s `fh-node-cool`，描边从橙红渐变回默认色；`failed` 保持 danger、不冷却；
- 运行 benchmark：节点下方无边框暗淡 HUD，标题栏为 `tok N` + ms 计时（100ms 增量），下方最多 80px 的尾部输出；`nodeMetrics` 由运行事件投影，adapter 注入 `CanvasNodeData.runMetrics`，`node:stream` 的 `HarnessValue.text` 进入尾部文本；
- 新增截图场景 `designer-stream`：本地 mock Ollama（/api/tags、/api/show、流式 /api/chat）触发真实 Model Call 流式输出，验证运行中 / 冷却两帧。

## 5. 上游显示与运行刷新收口

- Merge / Branch / Loop 等「值由运行期决定」的上游节点，锁定字段不再显示原始 type id（`core.merge`），改为节点标题 + 「输出」（如 `Merge 输出`）；
- HUD 指标改为 150ms 节流写入画布：完整指标在 ref 中继续累加，节点 / 边状态仍然逐批即时更新，避免每个 stream 片段都重建整张画布；
- 运行警戒环改用四条 2px 边框拼成，去掉 `mask-composite`，避免缩放画布上的遮罩合成开销与大范围重绘。

## 6. Filter / Combine（ADR-045）

- `core.merge` 更名并改为 `core.filter`（行为不变：`a ?? b`），节点库只展示 Filter；旧 `core.merge` 保留为 legacy 注册项，旧图 / 旧 run 继续可运行，但在节点库隐藏；
- 新增 `core.combine`：两个 `text` 输入 + `separator`（默认空串），按顺序拼接为单个 `text` 输出；单路透传、双路缺失执行期 `MissingValue`；节点 Body 内联分隔符输入；
- FH 加载文档时递归迁移 `core.merge → core.filter`（含 Loop / ForEach / Subgraph 内嵌图），保存后写回新类型；
- 图标：Filter 漏斗、Combine 合并图标；新增截图场景 `designer-filter-combine` 与基线；
- wireclaw 新增 `harness-filter-combine` 测试（Filter / Combine / 旧别名），编辑器目录 schema 数随 Combine 更新。

## 本会话贡献

### 自定义运行页

- 新增 `flow-runner` 工作台：`View` 为固定工作流配置页，`RunView` 为只读运行页。
- 运行页包含：固定只读画布、运行 / 暂停 / 继续 / 取消、运行状态、节点时间线、返回配置；结果与会话仍由浮动面板承载。
- `defaultWorkbenchTitle` 与工作台注册表接入 `flow-runner`；App 将结果面板层扩展到该工作台。

### 动画原语（ADR-023）

- **pulse**：`SciFiNode` 的 running 状态增加 CSS box-shadow 脉冲。
- **flow**：活跃边继续使用既有流动虚线。
- **focus**：运行页把当前 running 节点转换为 `CanvasView.focusNode`（带 seq），视口自动跟随。
- 全部动画遵守 `prefers-reduced-motion`；不引入动画库，也不提前实现完整 `CanvasAnimationApi`。

### 运行模式收口

- `harness-designer` 运行阶段保持「画布 + 运行上下文条 + 结果 / 会话面板」；`flow-runner` 作为固定只读运行页参考。
- 实例 `mode / runId / sessionId` 持久化、设计 ↔ 运行入口、双区导航、运行消息写入继续可用。
- 视觉基线补齐设计 → 运行 → 结果 / 会话链路。

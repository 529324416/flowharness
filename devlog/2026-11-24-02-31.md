## 遇到的问题

1. **Electron 进程写盘全被拒（EPERM）**：在这个受限会话里，main 的 Node `fs` 对 AppData、temp、甚至工作区都返回 EPERM（普通 Node 进程可以写）。这不是代码问题。
   - 处理：AppConfig 写失败 → 内存态 + 告警，应用照常启动；WorkspaceStore 创建失败 → 列表返回空；smoke 只验证读路径。
   - 正常桌面终端不受影响；文档已记录。
2. **单实例锁无法启用**：`app.requestSingleInstanceLock()` 需要创建 Chromium 单例锁文件，同环境下失败并让应用直接退出。已移除，记为后续在有写权限的环境恢复。
3. **Vitest 配置 ESM 警告**：desktop 是 CJS 包，`vitest.config.ts` 触发 Vite config loader 警告；改名 `vitest.config.mts` 解决。
4. **`contracts` 与 `fflate` 的打包策略**：contracts 是 TS 源码必须打包；`fflate` 是普通 CJS 依赖，保持外部化即可。

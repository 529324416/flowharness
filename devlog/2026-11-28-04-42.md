## 1. 设置页改为列表 + 属性栏

- **API 密钥**页签：移除列表上方的内联新增表单，整块区域改为「左侧密钥列表 + 右侧属性栏」；列表项显示名称、协议、指纹与状态，右侧显示指纹、Base URL、验证 / 创建 / 更新时间与最近错误；
- 密钥属性栏保留重新验证 / 替换 / 删除；替换在当前属性栏内展开输入行；
- **Provider**页签采用同一结构：左侧 Provider 列表显示名称、适配器与健康状态，右侧属性栏直接编辑名称 / 适配器 / API 密钥 / Base URL / 默认模型 / 启用，并展示模型目录与刷新时间；
- Provider 的「保存」只在草稿与当前 profile 不一致时可用；刷新模型 / 删除保留在属性栏；
- 选中项跟随库刷新：仍存在则保留，删除后回退到第一条；新增成功后自动选中新条目。

## 2. 新增表单移入 Modal

- 两个 Modal 均复用 `ui/Dialog`，嵌套在设置页之上；表单错误在 Modal 内展示，全局成功 / 失败提示仍留在设置页顶部。

## 5. 运行动画修订

- 边动画从百分比进度扫过改为沿连线移动的白色段：`pathLength=100`，白色段占 24%，`stroke-dashoffset` 24→-76，900ms 线性循环；方向固定为**输出端口 → 输入端口**；不读取 token 计数，也不随 `node:stream` 事件重启；
- 修复边动画被 token / 指标刷新重启的根因：画布投影合并时保留 React Flow 节点内部字段（`measured` / `internals` / `handleBounds`），并只在边 id / status 变化时重建边（`canvas/view/flow-merge.ts`）；此前每次指标更新把节点替换成裸对象，边在重新测量期间失去端点、EdgeWrapper 卸载重建，CSS 动画从 0 开始；
- 运行态警戒环改为单一元素 + `padding-box` 遮罩：斜纹背景铺满整个矩形后只保留 2px 边框，四个角共用连续纹理，不再有四条边框拼接的断裂感；
- `prefers-reduced-motion`：边白段退化为整条静态白线，警戒环停止滚动；
- 测试：`flow-merge.test.ts` 3 项（内部字段保留 / 新增删除 / 边签名）；`designer-stream` 增加动画稳定性断言（同一 path、`startTime` 不变）。

## 6. Replace 节点

- wireclaw 新增 `core.replace`（ADR-046）：输入 `raw_text` / `keyword` / `replacement`，输出 `text`；
- 三个输入都可从端口传入，未连接时回退本地 config；`count` 默认 -1（全部），0 不替换，正数为最大次数；只做字面量替换，空 keyword 原样返回，缺 raw_text / keyword 执行期 MissingValue；
- FH 节点 Body 提供 raw_text 多行、keyword / replacement 输入与 count 数字输入；端口连接后对应字段变为上游锁定行；图标 `ReplaceAll`；
- 节点库更新为 19 个类型（14 个带 configSchema）；wireclaw 新增 `harness-replace`，FH catalog 测试同步。

## 7. 运行草稿与会话多选

- 运行默认创建临时草稿：写入 `sessions/.tmp/<sessionId>/session.json`，`SessionRecord.temporary = true`，不进入 Session 树；下一次运行清空 `.tmp`（ADR-047）；
- 标题栏运行按钮右侧新增「存草稿」开关，默认关闭；打开后运行直接写入草稿目录；运行中 / 暂停禁用；
- 会话历史面板对临时草稿显示「临时」标记与「存储草稿」按钮；`session:commitTemporary` 把临时草稿移入草稿目录并清除 `temporary`；移除原「打开设计器」入口；
- Session 树顶部固定一条虚线「临时」草稿行，关闭历史面板后可点击重新打开；该行不进入持久化树、不参与多选 / 批量操作；
- Session 树支持 Ctrl / Cmd / Shift 多选，打开中的会话始终属于选择；批量操作条提供全选 / 移动 / 删除 / 清除，批量右键菜单复用同一动作；批量删除后 App 清理已删除的当前会话；
- 测试：`session-store.test.ts` 新增临时草稿 / 提交 / 非临时 no-op / 自动保存时丢弃旧临时 4 项；截图场景 `run-draft` / `session-multi-select` / `session-batch-delete` / `session-batch-move`。

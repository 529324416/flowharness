## 本会话贡献

### 对外命名与工作流菜单

- 面向用户的名称统一为 **工作流（workflow）**；`GraphDocument` 只保留为 wireclaw / contracts 内部类型名。左栏、标题栏、菜单、错误提示、空态同步。
- 工作流列表支持右键菜单，与右上角操作菜单共用同一份动作定义、重命名 / 删除 / 导入对话框；右键菜单额外提供「打开工作流」。
- 工作流导出支持指定目标 id，右键非当前工作流时不会误导出当前项。

### Session 导航

- 新增 `SessionNavigation`：递归文件夹树、展开 / 折叠、搜索、新建文件夹 / 会话、重命名、移动、删除、草稿目录标识。
- Session 树节点与文件夹均带右键菜单；移动对话框列出根目录与所有文件夹。
- 新增 `session:rename` / `session:delete` IPC、preload/bridge 与 `SessionStore.renameSession`。
- 设计/运行模式切换：`harness-designer` 设计左栏为工作流列表，运行左栏为 Session 树；切换工作台 / 工作区自动回到设计模式。

### 会话历史面板

- `SessionHistoryView` 增加 `embedded` 模式，嵌入 Canvas 的 `session-history` 浮动 Panel；点击 Session 树节点打开。
- 保留消息、工具调用、附件、错误与空态；运行会话先显示 entryCount，RunResult 回放留到 M7.4。
- 浮动 Panel 增加 `session-history` 默认尺寸（420×520）与左上方默认位置，避免覆盖 Inspector。

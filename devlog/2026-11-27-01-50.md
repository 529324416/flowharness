## 本会话贡献

### 窗口标题栏与 Windows 对齐

- 透明无边框窗口下 Electron 会吞掉 `SC_MAXIMIZE`（见 `native_window_views_win.cc`），导致标题栏双击失效；main 用 `hookWindowMessage(WM_SYSCOMMAND)` 恢复双击最大化 / 还原，并对 `SC_MOVE` 做“拖动最大化标题栏先还原”，还原后按光标水平比例放回标题栏下方。
- 增加 `WM_NCLBUTTONDBLCLK` 兜底与 250ms 去重；去掉了 renderer 里的 `onDoubleClick` 切换，避免与原生消息重复触发。
- 最大化状态在 `maximize` / `unmaximize` / `restore` / `focus` / `resize` 与 `did-finish-load` 后广播；`WindowControls` 在 focus / resize / visibilitychange 时兜底查询，修复“已最大化仍显示普通图标”。
- 最大化 / 还原按钮改用 Windows 风格的 10×10 描边图标。

### 删除当前工作流

- `WorkspaceStore.deleteDocument` 删除前解除工作台引用：清理 `graphs`、`plan.graphs`、`plan.bindings`，计划为空置 `null`；不再返回 `E_CONFLICT`（ADR-025）。
- renderer 删除后刷新文档与工作台实例，按“上一条渲染过的图 → 实例仍绑定的图 → 列表第一条”回退；没有剩余工作流时进入空态，不再自动新建。
- 工作台 `canOpen` 允许空绑定；设计器空态提供「新建工作流」入口，创建后自动重新绑定。
- 更新 `workspace-store` 用例：引用解除后删除成功、计划与绑定清理、空绑定保留。

### Session 树与 Ribbon

- Session 树文件行比同层文件夹行多缩进一个展开箭头位（20px），会话图标与文件夹图标对齐；嵌套文件夹按层级缩进。
- Ribbon 宽度 52 → 46，左右留白收窄，图标尺寸不变。

## 本会话贡献

### 契约

- `WorkbenchDefinition` 新增 `splitNavigation: { top, bottom }`；`WorkbenchNavigationProps` 新增 `navSection`，供导航组件切换到分区紧凑样式。
- `harness-designer` 声明 `splitNavigation: { top: "design", bottom: "run" }`：上半区工作流，下半区 Session 树；`mode` 只影响主视图。
- ADR-021 记录双区导航的动机与取舍（替代按 mode 二选一）。

### Shell 布局

- 新增 `SplitSidebar`：上下两区共享侧栏宽度；横向分隔条可拖动调整高度比例（默认 50/50，范围 20%–80%），比例写入 `localStorage["fh.sidebar.split"]`；键盘方向键可微调。
- `NavigationPanel` 增加 `section` 变体：占满分区高度、不重复宽度拖拽与收起按钮；收起按钮只保留在上半区；分区页头高度收敛到 34px。
- App 左栏渲染改为：声明 `splitNavigation` 的工作台渲染 `SplitSidebar`，其余工作台继续按 `mode` 渲染单一导航。

### 验证

- FH：34 个测试文件 / 172 项通过（新增导航槽位解析测试）；
- `pnpm typecheck` / `pnpm build` / `pnpm smoke` 通过；
- 视觉基线：[双区导航](./assets/ui-m7-split-nav.png)。

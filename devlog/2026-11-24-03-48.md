# 2026-11-24 03:48 — Windows 一键启动 run.bat

## 目标

让 GUI 测试不依赖记命令：双击根目录 `run.bat` 即可启动开发环境。

## 行为

1. `cd /d "%~dp0"` 定位到仓库根目录；
2. 检查 `node` / `pnpm`，缺失时给出安装提示；
3. `node_modules` 不存在 → `pnpm install`；
4. `vendor/wireclaw/dist/browser/index.js` 不存在 → `pnpm build:wireclaw`；
5. 启动 `pnpm dev`（`run.bat --no-sandbox` → `pnpm dev:no-sandbox`）；
6. 失败时打印提示并 `pause`，正常退出返回 0。

## 验证

以受控方式运行（`FLOWHARNESS_SMOKE=1` + `--no-sandbox`），等到渲染进程上报自检 run：

```text
[main] renderer-ready {"phase":"run","data":{"runId":"run_e334...","status":"completed","error":null}}
```

进程随后自行退出，说明 dev server + Electron + 自检链路都被脚本正确拉起。

## 说明

- 批处理必须保持 CRLF：新增 `.gitattributes` 固定 `*.bat` 为 `eol=crlf`，避免 cmd 解析 label 异常；
- 普通桌面终端直接双击即可；受限会话（CI/沙箱）需要 `--no-sandbox`；
- 脚本只负责开发模式；生产构建与打包在后续阶段接入。

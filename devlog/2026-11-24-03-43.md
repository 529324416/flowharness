### tokens

`styles/tokens.css` 重写为唯一视觉事实源：

- 深色默认（`#0a0f10` 背景、青绿 `#2dd4bf` 主色），亮色用 `[data-theme="light"]` 覆盖；
- 类别：表面 / 文本 / 边框 / 主色 / 状态（含 `-soft`）/ 画布 / 阴影 / 圆角 / 间距 / 字体 / 字号 / 动效 / 尺寸 / 层级；
- 默认主题改为 dark：AppConfig 默认值、首帧 `localStorage` 缓存、ThemeProvider 持久化同步更新。

### 组件原语 `ui/`

Button、IconButton、Badge、StatusDot（含 skipped/running pulse）、Kbd、Input、Panel、
EmptyState、Alert、Tooltip、Menu、ContextMenu、Dialog、Tabs；Radix 提供行为，CSS Modules 提供视觉。

### 六区外壳 `shell/`

- TopBar（品牌/工作区菜单/运行控制占位/主题/面板开关/设置）；
- LeftRail（设计器 / 诊断 / 样式指南 / 设置）；
- Inspector（选中节点属性示例，非设计器视图显示空状态）；
- BottomPanel（运行日志 / 问题，消费真实 run 事件流）；
- StatusBar（run 状态、工作区路径、视图、缩放）；
- AppShell 负责 grid 布局与面板收起。

### 画布样张 `canvas-preview/`

- `NodeCard`：图标 + 标题 + 状态点 + 类型 + 摘要 + 左右端口；
- `CanvasPreview`：点阵网格、5 个节点（completed / running+selected / failed / skipped / idle）、
  4 条贝塞尔连线（默认/流动/失败）、小地图、缩放控件、样张标记；
- 几何常量在 `canvas/metrics.ts`，Phase 3 的 react-flow adapter 复用同一套。

### Styleguide 视图

覆盖色彩、字体、间距/圆角、按钮、徽标/状态、输入、浮层（Tooltip/Menu/ContextMenu/Dialog）、
Tabs、画布节点六态、连线三态、Alert/EmptyState、快捷键。

## 问题与取舍

1. **renderer 体积**：Radix + Lucide + wireclaw 浏览器构建使 renderer 从 630 kB 增至 991 kB；
   先记录，Phase 3 后按需做 manualChunks/懒加载。
2. **截图验证不可用**：`capturePage` 在受限会话中挂起（Phase 2 已遇到），本阶段继续用 DOM/样式断言。
3. **主题默认值变更**：dark 成为默认，首帧用 localStorage 缓存避免闪白；AppConfig 仍为最终来源。
4. **「运行控制」暂为占位**：真实运行/暂停/停止在 Phase 3 接入画布后生效。
